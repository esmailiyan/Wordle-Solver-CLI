# Wordle Solver
This code is for find the daily [wordle](https://www.nytimes.com/games/wordle/index.html) in minimum trying.

### Basic Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/esmailiyan/WordleSolver.git
   ```
2. Go to the project directory:
    ```bash
    WordleSolver
    ```
3. Run the code:
    ```bash
    python3 main.py
    ```
- in each step, my code suggest the specific 5-letter words. you should submit that in the [site](https://www.nytimes.com/games/wordle/index.html) and get its color to get next word.

#### Colors Code
- `y` : Yellow
- `g` : Green
- `b` : Black

Enjoy :)
